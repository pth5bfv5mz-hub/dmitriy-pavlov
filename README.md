# Дмитрий Павлов

Личный ИИ-ассистент Сумрака в духе Джарвиса: веб-приложение (PWA) для iPhone. Ставится на экран «Домой» как отдельное приложение. Сервера нет: всё хранится на телефоне, нейросети вызываются напрямую по ключам пользователя.

## Версия 3

- **Несколько мозгов с автопереключением.**
  - Gemini (самый умный, с VPN): сам находит доступные ключу модели.
  - Mistral и Z.ai GLM: работают из России без VPN.
  - Claude и любая совместимая с OpenAI нейросеть.
  - Если один недоступен, отвечает следующий.
- **Интернет.** Поиск Google и чтение ссылок (Gemini), веб-поиск Claude, инструменты `web_search` / `read_url` / `get_weather` для остальных (Tavily, Википедия, Jina Reader, Open-Meteo).
- **Голос, который работает на iPhone.**
  - Запись микрофона с определением конца фразы по тишине.
  - Распознавание нейросетью (Gemini или Mistral Voxtral), потому что встроенное распознавание iOS не работает в приложениях с экрана «Домой».
  - Полноэкранный голосовой разговор с перебиванием.
  - Живой голос Gemini TTS; запасной — голос iPhone.
- **Память.**
  - Профиль — всегда в контексте.
  - Факты с темой и важностью; отбор по важности, свежести и смыслу (как в Generative Agents).
  - Устаревшее не стирается, а помечается.
  - Ежедневная рефлексия с выводами, дневник разговоров, наведение порядка.
- **Обучение.**
  - Навыки по команде «научись» (с подтверждением).
  - Уроки из поправок и оценок 👎.
  - Защита: навыки и правила создаются только по словам самого Сумрака.
- **Знания.** Тексты, ссылки, PDF и Word (до сотен страниц, читаются на телефоне через pdf.js/mammoth без лимитов), фото: нарезка на фрагменты, конспект, гибридный поиск (BM25 + векторы Gemini, слияние RRF). Сканы распознаёт Gemini.
- **Учёба.** Карточки с интервальным повторением.
- **Режимы-эксперты.** Учитель, Учёный, Философ, Психолог (КПТ), Аналитик, Коуч, Кибербезопасность (этичная: защита и учёба, не атаки); «Глубже» (pro-модель и самопроверка); инкогнито.
- **Проактивность.** Утренняя сводка, напоминания о делах и обещаниях; повторяющиеся напоминания и отправка в «Напоминания» iPhone.
- **Безопасность.** Протокол кризисных разговоров с российскими телефонами помощи, честность о том, что это ИИ.
- **Про лимиты.** Счётчик запросов за день; при исчерпании бесплатного лимита — переход на запасной мозг или облегчённую модель, кнопки поиска в Яндексе/Google.
- **Проверка системы и резервная копия файлом.**

Пошаговая настройка: [guide.html](guide.html).

## Устройство кода

| Файл | Что внутри |
|---|---|
| `index.html`, `style.css` | интерфейс |
| `js/main.js` | сборка интерфейса: чат, голосовой разговор, вкладки, настройки, проверка |
| `js/brains.js` | нейросети, выбор моделей, переключение, распознавание и синтез речи, эмбеддинги |
| `js/prompt.js` | характер, правила мышления, режимы-эксперты, безопасность |
| `js/memory.js` | память, отбор фактов, навыки, уроки, рефлексия, дневник, карточки |
| `js/knowledge.js` | база знаний и поиск |
| `js/voice.js` | запись, определение тишины, воспроизведение |
| `js/store.js`, `js/util.js` | хранилище (localStorage + IndexedDB), утилиты |
| `lib/` | pdf.js и mammoth (чтение PDF и Word на устройстве) |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка на экран «Домой», офлайн-оболочка |
