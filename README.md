# Дмитрий Павлов

Личный голосовой ассистент Сумрака в духе Джарвиса. Веб-приложение (PWA), которое ставится на iPhone как отдельное приложение.

- **Мозг:** Google Gemini с поиском Google (бесплатный ключ). Запасные варианты: Claude по ключу или любая модель через OpenRouter/Groq. Для них подключены поиск по Википедии и погода Open-Meteo.
- **Голос:** распознавание речи на русском, режим «слушать „Дмитрий“» и ответы выбранным голосом iPhone.
- **Память:** сам запоминает важное о Сумраке из разговоров и раскладывает по темам. Старые разговоры сжимает в дневник, чтобы помнить их долго.
- **Ум:** поиск в интернете, чтение ссылок, разбор фото, календарь на две недели для точных дат, запасные модели при исчерпании лимита.
- **Дела и напоминания** (в том числе повторяющиеся): напоминает, пока приложение открыто. Через команду «ДП Напоминание» отправляет дела во встроенные «Напоминания» iPhone, и они звенят, даже когда приложение закрыто.
- **Заметки.**
- **Резервная копия:** все данные хранятся только на телефоне.

Пошаговая настройка лежит в [guide.html](guide.html), её же можно открыть в самом приложении.

## Публикация

Это статический сайт, сборка не нужна. Для GitHub Pages положи файлы этой папки в корень публичного репозитория и включи Pages (Settings → Pages → Deploy from a branch → `main` / root). Адрес будет такой: `https://<логин>.github.io/<репозиторий>/`.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | интерфейс |
| `style.css` | оформление (светлая и тёмная тема) |
| `app.js` | вся логика: нейросети, голос, память, напоминания |
| `sw.js` | офлайн-оболочка |
| `manifest.webmanifest`, `icons/` | установка на экран «Домой» |
| `guide.html` | инструкция для пользователя |
