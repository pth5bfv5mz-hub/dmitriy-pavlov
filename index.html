                Поиск Google, живой голос, распознавание речи, чтение фото и PDF. Ключ: aistudio.google.com/apikey (с VPN).

                Работает из России. Регистрация: console.mistral.ai → бесплатный план (Free / Experiment, нужен номер телефона) → API Keys → Create new key. Умеет распознавать речь.

                Ключ: z.ai → API Keys. Бесплатная модель glm-4.7-flash.
