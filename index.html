                  Нейросеть

                  Gemini — самый умный, бесплатно, нужен VPN

                  Поиск Google, живой голос, распознавание речи, чтение фото и PDF. Ключ: aistudio.google.com/apikey (с VPN).

                  Mistral — бесплатно, без VPN

                  Работает из России. Регистрация: console.mistral.ai → бесплатный план (Free / Experiment, нужен номер телефона) → API Keys → Create new key. Умеет распознавать речь.

                  Дополнительно, по желанию — каждая следующая нейросеть добавляет свой бесплатный лимит:

                  Z.ai GLM — бесплатно, без VPN

                  Ключ: z.ai → API Keys. Бесплатная модель glm-4.7-flash.

                  OpenRouter — бесплатные модели (DeepSeek, Qwen, Llama)

                  Ещё один независимый бесплатный лимит. Регистрация: openrouter.ai (через Google или почту) → Keys → Create Key. Без пополнения — около 50 ответов в день; после разового пополнения на $10 — около 1000 в день (бесплатные модели деньги не тратят).

                  Голос

                  Проверяю…
