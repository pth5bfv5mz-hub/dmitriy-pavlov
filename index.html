Дела и напоминания

    Кнопка ⏰ добавляет дело во встроенные «Напоминания» iPhone, и оно сработает, даже когда приложение закрыто. Настройка один раз: см. «Настройки → Напоминания iPhone».

      Что я о тебе знаю

      Я сам запоминаю важное из наших разговоров и раскладываю по темам. Лишнее можно удалить.

        История наших разговоров

        Старые разговоры я сжимаю в краткую сводку, чтобы помнить их и через месяц.

        Мозг

        Получить бесплатно: aistudio.google.com/apikey → «Create API key» → скопируй и вставь сюда.

        «Умный и быстрый» подходит для всего. «Самый умный» думает дольше, но бесплатных запросов в день у него меньше. «Экономный» — когда лимит важнее глубины. Если лимит выбранной модели кончится, я сам переключусь на запасную.

        Ключ: console.anthropic.com. Платно, по факту использования.

        У таких моделей нет поиска Google; вместо него я ищу в Википедии и смотрю погоду через Open-Meteo.

        Голос

        Мужской голос «Юрий» скачивается один раз: Настройки iPhone → Универсальный доступ → Устный контент → Голоса → Русский → Юрий. После этого перезапусти приложение.
